# ARIA Presentation & Slide Decks 📊

This directory contains presentation materials, slide outlines, visual assets, and PowerPoint (`.pptx`) decks for **ARIA (Autonomous Research Intelligence for Analytics)**.

## 📂 Directory Structure

- `assets/` - Embedded charts, diagrams, and visual media exported for presentations.
- `templates/` - Slide layout templates and theme guidelines.
- `decks/` - Generated presentation decks and slide outlines.
