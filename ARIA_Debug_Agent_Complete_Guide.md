# ARIA: Debug Agent (Error Fixing Code Agent)
## Complete Implementation Guide

---

## 1. WHAT IS THE DEBUG AGENT?

The **Debug Agent** is a new specialized agent that catches, analyzes, and fixes code errors generated by the Data Agent and Stats Agent.

### Problem It Solves

**Before (without Debug Agent):**
```
User Question
    ↓
Data Agent generates code
    ↓
Code executes → ERROR (e.g., KeyError, TypeError, TimeoutError)
    ↓
Error bubbles up to Orchestrator
    ↓
❌ Task marked FAILED
    ↓
Human must investigate and rewrite the query manually
```

**After (with Debug Agent):**
```
User Question
    ↓
Data Agent generates code
    ↓
Code executes → ERROR
    ↓
✅ Debug Agent catches error
    ↓
Debug Agent analyzes:
   - What went wrong?
   - Why did it fail?
   - How to fix it?
    ↓
Debug Agent proposes & tests fix
    ↓
Re-runs corrected code
    ↓
❌ Still fails? Try again (max 3 iterations)
    ↓
✅ Success or escalate to human with detailed diagnosis
```

## 2. AGENT ARCHITECTURE

### Debug Agent in ARIA Pipeline

```
Data Agent generates code
        ↓
   ┌────────────┐
   │ Execution  │
   │  Sandbox   │
   └────┬───────┘
        ↓
   ┌─── ERROR? ───┐
   │     YES      │
   └──────┬───────┘
          ↓
    ╔═════════════════╗
    ║  DEBUG AGENT    ║  ← NEW
    ║  • Analyze err  ║
    ║  • Propose fix  ║
    ║  • Test fix     ║
    ║  • Retry        ║
    ╚═════╤═══════════╝
          ↓
    ┌─ Success? ─┐
    │    YES     │ (max 3 attempts)
    └──┬──────┬──┘
       │      │
       YES    NO
       ↓      ↓
    PASS   ESCALATE
          (to Critic)
```

### Debug Agent Responsibilities

| Responsibility | Details |
|---|---|
| **Error Detection** | Capture execution errors, tracebacks, timeouts |
| **Error Analysis** | Classify error type (syntax, runtime, logic, timeout) |
| **Root Cause Diagnosis** | Identify why the error occurred (schema mismatch, missing column, type error, etc.) |
| **Fix Proposal** | Generate corrected code that addresses the root cause |
| **Fix Testing** | Re-execute corrected code in sandbox |
| **Iteration** | Retry up to 3 times; escalate if unfixable |
| **Logging** | Record all attempts, errors, and fixes for audit trail |

## 3. DEBUG AGENT DESIGN

### Input/Output Schema

```python
from pydantic import BaseModel
from typing import Optional, List

class CodeExecutionError(BaseModel):
    error_type: str  # "SyntaxError", "KeyError", "TimeoutError", etc.
    error_message: str
    traceback: str
    code_executed: str
    execution_time_ms: float

class DebugAttempt(BaseModel):
    attempt_number: int  # 1, 2, 3
    original_error: CodeExecutionError
    proposed_fix: str  # Fixed code
    fix_explanation: str  # Why this should work
    execution_result: Optional[str]  # Result if successful
    success: bool

class DebugAgentOutput(BaseModel):
    task_id: int
    original_question: str
    status: str  # "FIXED", "FAILED_MAX_RETRIES", "ESCALATED"
    attempts: List[DebugAttempt]
    final_result: Optional[str]
    final_code: Optional[str]
    escalation_reason: Optional[str]  # If ESCALATED
```

### Debug Agent Workflow

```python
class DebugAgent:
    def __init__(self, llm_client, sandbox):
        self.llm = llm_client
        self.sandbox = sandbox
        self.max_retries = 3
        self.retry_count = 0
    
    def handle_error(self, error: CodeExecutionError, original_question: str):
        """Main entry point when code fails"""
        
        self.retry_count = 0
        attempts = []
        
        while self.retry_count < self.max_retries:
            self.retry_count += 1
            
            # Step 1: Analyze error
            analysis = self.analyze_error(error)
            
            # Step 2: Propose fix
            proposed_code = self.propose_fix(
                original_question,
                error,
                analysis,
                attempts  # Previous attempts for context
            )
            
            # Step 3: Test fix
            result = self.test_fix(proposed_code)
            
            # Step 4: Record attempt
            attempt = DebugAttempt(
                attempt_number=self.retry_count,
                original_error=error,
                proposed_fix=proposed_code,
                fix_explanation=analysis['explanation'],
                execution_result=result.get('output'),
                success=result['success']
            )
            attempts.append(attempt)
            
            # Step 5: Check if fixed
            if result['success']:
                return DebugAgentOutput(
                    status="FIXED",
                    attempts=attempts,
                    final_result=result['output'],
                    final_code=proposed_code
                )
            
            # Update error for next iteration
            error = result['error']  # New error from failed attempt
        
        # Max retries reached
        return DebugAgentOutput(
            status="FAILED_MAX_RETRIES",
            attempts=attempts,
            escalation_reason=f"Failed to fix after {self.max_retries} attempts"
        )
    
    def analyze_error(self, error: CodeExecutionError) -> dict:
        """Classify and understand the error"""
        
        prompt = f"""
Analyze this code execution error and provide:
1. Error classification (syntax, runtime, logic, timeout, missing resource)
2. Root cause (why did this error occur?)
3. What data/schema issue caused it
4. How to fix it

Error Type: {error.error_type}
Error Message: {error.error_message}
Traceback: {error.traceback}
Code: {error.code_executed}

Respond in JSON:
{{
    "classification": "...",
    "root_cause": "...",
    "schema_issue": "...",
    "fix_approach": "...",
    "explanation": "..."
}}
"""
        
        analysis = self.llm.query(prompt)
        return analysis
    
    def propose_fix(self, original_question, error, analysis, previous_attempts):
        """Generate corrected code"""
        
        # Build context about what was tried before
        attempt_history = "\n".join([
            f"Attempt {a.attempt_number}: {a.fix_explanation}"
            for a in previous_attempts
        ])
        
        prompt = f"""
The user asked: "{original_question}"

Code execution failed with:
Error: {error.error_type}
Message: {error.error_message}

Original code:
{error.code_executed}

Analysis:
- Root cause: {analysis['root_cause']}
- Schema issue: {analysis['schema_issue']}
- Fix approach: {analysis['fix_approach']}

Previous attempts (if any):
{attempt_history}

Generate CORRECTED pandas code that:
1. Fixes the identified issue
2. Doesn't repeat previous mistakes
3. Follows best practices
4. Includes error handling

Respond with ONLY the corrected Python code, no explanations.
"""
        
        fixed_code = self.llm.query(prompt)
        return fixed_code
    
    def test_fix(self, code: str) -> dict:
        """Execute the proposed fix"""
        
        try:
            result = self.sandbox.run_code(
                code,
                timeout=30,
                description="Debug Agent retry"
            )
            return {
                'success': True,
                'output': result
            }
        except Exception as e:
            return {
                'success': False,
                'error': CodeExecutionError(
                    error_type=type(e).__name__,
                    error_message=str(e),
                    traceback=traceback.format_exc(),
                    code_executed=code,
                    execution_time_ms=0
                )
            }
```

## 4. ERROR CLASSIFICATION

The Debug Agent should recognize and handle these error types differently:

### A. **Schema Errors** (Most Common)
```python
# Error: KeyError: 'Churn_Rate' (column doesn't exist)

# Root cause: Column name mismatch
# Fix: Use correct column name from schema
# Detection: Check df.columns before accessing

original_code = """
churn_rate = df['Churn_Rate'].mean()  # KeyError!
"""

fixed_code = """
# First, check available columns
print(df.columns)
# Then use correct name
churn_rate = df['Churn'].mean()  # Assuming 'Churn' is binary
"""
```

### B. **Type Errors**
```python
# Error: TypeError: unsupported operand type(s) for /: 'str' and 'int'

# Root cause: Column contains strings, not numbers
# Fix: Convert to numeric first

original_code = """
df['revenue'].sum() / df['customers'].sum()  # TypeError if 'revenue' is string
"""

fixed_code = """
df['revenue'] = pd.to_numeric(df['revenue'], errors='coerce')
df['customers'] = pd.to_numeric(df['customers'], errors='coerce')
result = df['revenue'].sum() / df['customers'].sum()
"""
```

### C. **Timeout Errors**
```python
# Error: TimeoutError (code ran > 30 seconds)

# Root cause: Query is inefficient or dataset too large
# Fix: Add limits, optimize query, sample data

original_code = """
# Loading 1 billion rows
df = pd.read_csv('huge_dataset.csv')
for row in df:  # Iterating over 1B rows!
    ...
"""

fixed_code = """
# Load only needed columns and sample
df = pd.read_csv(
    'huge_dataset.csv',
    usecols=['col1', 'col2', 'col3'],
    nrows=100000  # Sample for analysis
)
# Use vectorized operations instead of loop
result = df.groupby('col1')['col2'].sum()
"""
```

### D. **Memory Errors**
```python
# Error: MemoryError (ran out of RAM)

# Root cause: Loading too much data at once
# Fix: Process in chunks, use generators

original_code = """
df = pd.read_csv('huge_file.csv')  # MemoryError
"""

fixed_code = """
# Read in chunks
chunks = []
for chunk in pd.read_csv('huge_file.csv', chunksize=50000):
    processed = chunk[chunk['value'] > 0]
    chunks.append(processed)

df = pd.concat(chunks, ignore_index=True)
"""
```

### E. **Logic Errors** (Hardest to Detect)
```python
# Error: No runtime error, but result is wrong/suspicious

# Root cause: Logic error in the code
# Detection: Critic Agent notices mismatch in values
# Fix: Debug Agent rewrites logic

original_code = """
# Trying to calculate churn rate, but logic is wrong
churn_rate = df['Churn'].sum() / len(df)  # Missing filter
"""

fixed_code = """
# Correct logic with proper filtering
churned_customers = (df['Churn'] == 'Yes').sum()
total_customers = len(df)
churn_rate = churned_customers / total_customers if total_customers > 0 else 0
"""
```

                    # Debug couldn't fix it
                    return {
                        'status': 'FAILED_AFTER_DEBUG',
                        'error': str(e),

        return result

### File: `agents/debug_agent.py`

```python
import json
import traceback
from typing import Optional, List, Dict
from datetime import datetime
import logging
from pydantic import BaseModel

logger = logging.getLogger(__name__)

class CodeExecutionError(BaseModel):
    error_type: str
    error_message: str
    traceback: str
    code_executed: str
    execution_time_ms: float

class DebugAttempt(BaseModel):
    attempt_number: int
    original_error: CodeExecutionError
    proposed_fix: str
    fix_explanation: str
    execution_result: Optional[str] = None
    success: bool

class DebugAgentOutput(BaseModel):
    task_id: int
    original_question: str
    status: str  # FIXED, FAILED_MAX_RETRIES, ESCALATED
    attempts: List[DebugAttempt]
    final_result: Optional[str] = None
    final_code: Optional[str] = None
    escalation_reason: Optional[str] = None
    timestamp: str

class DebugAgent:
    def __init__(self, llm_client, sandbox, max_retries=3):
        """
        Args:
            llm_client: LLM client (Ollama or Claude)
            sandbox: Code execution sandbox
            max_retries: Maximum number of fix attempts
        """
        self.llm = llm_client
        self.sandbox = sandbox
        self.max_retries = max_retries
        self.retry_count = 0
    
    def handle_error(self, 
                    error: CodeExecutionError, 
                    original_question: str,
                    task_id: int = 0) -> DebugAgentOutput:
        """
        Main entry point when code execution fails
        """
        
        self.retry_count = 0
        attempts = []
        current_error = error
        
        logger.info(f"[DebugAgent] Starting error recovery for task {task_id}")
        logger.info(f"[DebugAgent] Error: {error.error_type} - {error.error_message}")
        
        while self.retry_count < self.max_retries:
            self.retry_count += 1
            logger.info(f"[DebugAgent] Attempt {self.retry_count}/{self.max_retries}")
            
            # Step 1: Analyze error
            analysis = self._analyze_error(current_error)
            logger.debug(f"[DebugAgent] Analysis: {analysis}")
            
            # Step 2: Propose fix
            proposed_code = self._propose_fix(
                original_question,
                current_error,
                analysis,
                attempts
            )
            logger.debug(f"[DebugAgent] Proposed fix:\n{proposed_code}")
            
            # Step 3: Test fix
            result = self._test_fix(proposed_code)
            
            # Step 4: Record attempt
            attempt = DebugAttempt(
                attempt_number=self.retry_count,
                original_error=current_error,
                proposed_fix=proposed_code,
                fix_explanation=analysis['explanation'],
                execution_result=result.get('output'),
                success=result['success']
            )
            attempts.append(attempt)
            
            # Step 5: Check if fixed
            if result['success']:
                logger.info(f"[DebugAgent] ✓ Error fixed on attempt {self.retry_count}")
                return DebugAgentOutput(
                    task_id=task_id,
                    original_question=original_question,
                    status="FIXED",
                    attempts=attempts,
                    final_result=result['output'],
                    final_code=proposed_code,
                    timestamp=datetime.now().isoformat()
                )
            
            # Update error for next iteration
            current_error = result['error']
            logger.warning(f"[DebugAgent] Fix attempt {self.retry_count} failed: {current_error.error_type}")
        
        # Max retries reached
        logger.error(f"[DebugAgent] Max retries ({self.max_retries}) exceeded")
        return DebugAgentOutput(
            task_id=task_id,
            original_question=original_question,
            status="FAILED_MAX_RETRIES",
            attempts=attempts,
            escalation_reason=f"Failed to fix after {self.max_retries} attempts",
            timestamp=datetime.now().isoformat()
        )
    
    def _analyze_error(self, error: CodeExecutionError) -> dict:
        """Classify and understand the error using LLM"""
        
        prompt = f"""
Analyze this code execution error and provide structured analysis:

Error Type: {error.error_type}
Error Message: {error.error_message}
Traceback (last 3 lines): {error.traceback.split(chr(10))[-3:]}

Code that failed:
```python
{error.code_executed}
```

Respond with a JSON object containing:
{{
    "classification": "One of: [schema_error, type_error, timeout, memory_error, logic_error, other]",
    "root_cause": "Why this error occurred (be specific)",
    "affected_part": "Which line/section caused the error",
    "schema_issue": "If applicable, what data/column issue caused it",
    "fix_approach": "How to fix this error",
    "explanation": "Clear explanation of the fix strategy",
    "confidence": 0.0-1.0
}}

Be concise and technical.
"""
        
        response = self.llm.query(prompt)
        
        try:
            analysis = json.loads(response)
        except json.JSONDecodeError:
            # Fallback if LLM doesn't return valid JSON
            analysis = {
                "classification": "other",
                "root_cause": error.error_message,
                "fix_approach": "Rewrite the code with error handling",
                "explanation": "Original code failed",
                "confidence": 0.5
            }
        
        return analysis
    
    def _propose_fix(self, 
                    original_question: str,
                    error: CodeExecutionError,
                    analysis: dict,
                    previous_attempts: List[DebugAttempt]) -> str:
        """Generate corrected code"""
        
        attempt_history = ""
        if previous_attempts:
            attempt_history = "Previous failed attempts:\n"
            for attempt in previous_attempts:
                attempt_history += f"\n- Attempt {attempt.attempt_number}: {attempt.fix_explanation}\n"
                attempt_history += f"  Error: {attempt.original_error.error_type}\n"
        
        prompt = f"""
Fix this code error.

Original Question: "{original_question}"

Failed Code:
```python
{error.code_executed}
```

Error Analysis:
- Classification: {analysis.get('classification', 'unknown')}
- Root Cause: {analysis.get('root_cause', 'Unknown')}
- Fix Approach: {analysis.get('fix_approach', 'Rewrite')}
- Explanation: {analysis.get('explanation', '')}

{attempt_history}

Generate CORRECTED pandas/Python code that:
1. Fixes the identified issue
2. Does NOT repeat previous mistakes
3. Includes basic error handling (try/except for critical operations)
4. Adds data validation (check dtypes, nulls, missing columns)
5. Follows pandas best practices

Return ONLY the corrected code, no explanations or markdown.
"""
        
        fixed_code = self.llm.query(prompt)
        
        # Clean up code (remove markdown if present)
        if fixed_code.startswith("```"):
            fixed_code = fixed_code.split("```")[1]
            if fixed_code.startswith("python"):
                fixed_code = fixed_code[6:]
        
        return fixed_code.strip()
    
    def _test_fix(self, code: str) -> dict:
        """Execute the proposed fix in sandbox"""
        
        try:
            result = self.sandbox.run_code(
                code,
                timeout=30,
                description="Debug Agent fix attempt"
            )
            return {
                'success': True,
                'output': result
            }
        except Exception as e:
            error = CodeExecutionError(
                error_type=type(e).__name__,
                error_message=str(e),
                traceback=traceback.format_exc(),
                code_executed=code,
                execution_time_ms=0
            )
            return {
                'success': False,
                'error': error
            }
    
    def log_debug_session(self, output: DebugAgentOutput, log_file: str = "logs/debug_agent.log"):
        """Log debug session for audit trail"""
        
        log_entry = {
            "timestamp": output.timestamp,
            "task_id": output.task_id,
            "original_question": output.original_question,
            "status": output.status,
            "attempts": len(output.attempts),
            "success": output.status == "FIXED",
            "attempts_detail": [
                {
                    "attempt": a.attempt_number,
                    "error_type": a.original_error.error_type,
                    "fix_explanation": a.fix_explanation,
                    "success": a.success
                }
                for a in output.attempts
            ],
            "escalation_reason": output.escalation_reason
        }
        
        with open(log_file, 'a') as f:
            f.write(json.dumps(log_entry) + "\n")
        
        logger.info(f"[DebugAgent] Session logged: {log_entry}")
```
